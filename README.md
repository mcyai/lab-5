# Lab 5 - React Product Dashboard

## File Organization

- `src/App.jsx` - root component, holds the state (`showProducts`, `name`)
- `src/components/ProductList.jsx` - product data and list rendering with `.map()`
- `src/components/Product.jsx` - shows one product's title and price
- `src/components/Card.jsx` - wrapper that renders its `children`
- `src/main.jsx` - entry point

## Challenges

- Understanding how to pass data with props
- Making the input a controlled input
- Using `id` as the key instead of the array index
